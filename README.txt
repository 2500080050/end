# Signup Page

A responsive signup page made with HTML, CSS, and JavaScript.

## Files
- `index.html` — page structure
- `style.css` — layout and styling
- `script.js` — password visibility and form validation

## How to run
1. Extract the ZIP file.
2. Open the `index.html` file in any modern web browser.
3. Fill in the form and press **Create account** to test the validation.

Note: This is a front-end demo. It validates the form in the browser but does not create or store a real user account. A backend and database are needed for real registration.
